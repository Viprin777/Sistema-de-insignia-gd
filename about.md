# Badge System

Earn collectible badges for everything you do in Geometry Dash.

- **38 badges** across 6 tiers: Bronze, Silver, Gold, Platinum, Diamond and Special
- Slide-in **unlock popups** with the achievement sound
- A **Badges** button on the main menu opens a scrolling collection screen with progress bars, unlock dates and All / Unlocked / Locked filters
- Badges for levels beaten, deaths, flawless runs, practice mode, stars, demons, user coins, secret coins, jumps, daily play streaks, and special time-of-day feats
- Stars, demons, coins and jumps are read from Geometry Dash's own stats, so your existing progress counts right away

## Notes

- Level and flawless badges count **different levels**, so replaying one easy level can't farm them.
- Local / editor levels don't count toward level badges.
- Everything can be reset from the **Reset** button on the Badges screen.
